## Actions before official registration

1. **Close the final-runtime safety-check gap.** `buildSafeRuntime()` checks its own output against a DOM element allowlist and disallowed browser primitives. The P011 builder then injects the fresh-surface wrapper *after* that check (`scripts/build-g678-alg-l12-origin-candidate.mjs:93-124`). Its final check compiles the script and searches for only a subset of the shared disallowed patterns; it does not rerun the shared final-runtime invariants. In particular, the emitted artifact has two `document.createElement("canvas")` sites, while the shared validator expects one for this zero-image asset (`scripts/build-safe-ffdec-canvas-adapter.mjs:2217-2225`). The added code is fixed and inspected here; this is a validation-contract gap, not evidence of unsafe behavior. Add an explicit final-artifact check with the second canvas intentionally allowlisted, including the shared forbidden primitives and document-member inventory, then rerun `--check`. Keep this page-specific and do not edit generated output by hand.
2. **Prove the six controls in the real host.** The current source test checks XML/action strings and server-rendered 0/0/3/3/6/6 button counts at frames 1/7/8/77/78/118. It does not click a button or prove glossary lookup, pause, close/resume, focus return, Replay reset, navigation cleanup, or English/Spanish responsive behavior. The module emits IDs `origin`, `point`, `coordinate-plane-cartesian-plane`, `x-axis`, `y-axis`, `intersect`; the source `KeyAttribute` strings differ, so the admitted descriptor must supply definitions by those exact IDs. Verify each request in the registered My Lesson path, plus a production-negative route. The candidate asset route is not yet served according to the QA receipt.
3. **Measure the fresh-canvas cost in My Lesson.** Every `render()` creates a new 800×600 surface, enhances its context, draws, and copies to the visible Canvas (`candidate-v2/canvas-renderer.js:11674-11696`). The FFDec sprite also allocates full-size canvases in mask branches. This fixed the observed Replay pixel drift, but the receipt gives no frame-time, dropped-frame, or repeated-Replay memory measurements. Check representative masked frames and a full 118-frame run at the 12-fps budget (83.3 ms/frame), then repeated Replay in the actual host. Treat a measured failure as a registration blocker; do not infer one from source inspection alone.
