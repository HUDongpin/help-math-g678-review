# Source-local slider and immediate-feedback generator

This maintained generator owns the proven common state, decoded-audio session and React host-control behavior of ALG001 L7 P011 and P012. It is a bounded two-consumer extraction, not a general animation framework.

P011 was implemented and admitted before this template extraction. Its existing files must reproduce byte-for-byte; this adoption does not rewrite its provenance or renew any historical evidence. P012 is generated from the same templates with independently audited source parameters. The page-specific full timeline, native text, graph vectors and presentation remain independently generated or maintained.

The source profile checks pin both source models and SWF hashes. Both sources increment attempts on every submission, resume immediately after a correct literal, open local wrong feedback at frame2, allow immediate Close, retain the first wrong value, and resume after the second wrong Close without resetting the count. Loop entry resets at each page's quiz frame. Shared clocks retain fractional audio position. Spanish audio remains explicit and independent.

Run `node tools/shared-page-factory/source-slider-feedback-v1/generate.mjs --check` to reproduce all consumers. Without `--check`, only missing outputs are created. Existing files are always compared. Maintain durable behavior in the templates and deliberately revalidate both consumers before changing admitted output. No original-runtime, listening, human, Owner, strict or publication acceptance is conferred.

P012 has a later source run at302 and an empty negative marker244. Its bounded pre-quiz clock filters those future entries; its post-quiz clock retains all three runs and the marker. P011 has no later entries and keeps its original output bytes. Both full source models retain every run.
