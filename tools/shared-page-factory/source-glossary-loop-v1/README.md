# Source glossary loop generator

This bounded shared template owns the common state, audio session and host controls of ALG001 L7 P010 and P013. Both source models are pinned: child timelines have no actions or clip actions, run ordinary cycles, and the glossary release sets a key, opens the host glossary and stops the animation. Spanish audio remains separate and explicitly triggered. There is no automatic page advance or lesson completion.

The generator reproduces the admitted P010 output byte for byte and creates P013 with independently audited213-frame/sprite57 parameters. P010 evidence is not renewed or rewritten by adoption. The source-specific native figure, mask reveal, coefficient changes and source geometry remain in each page's maintained presentation and generated model.

Run `node tools/shared-page-factory/source-glossary-loop-v1/generate.mjs --check`. Without that flag only missing files are created; existing bytes are compared. Change maintained templates deliberately, preserve source differences and rerun the affected session/host checks. This does not establish original runtime, fidelity, listening, human, Owner, strict or publication acceptance.
